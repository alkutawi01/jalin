# Jalin

**Jalin — oleh Adjung**

Jalin ialah platform bacaan sastera berilustrasi dan terkurasi untuk remaja 13–17 tahun.

Jalin bukan platform novel penuh. Ia mempertemukan **Cerpen, Bersiri, Terjemahan, Fragmen dan Sinopsis** dalam satu pengalaman membaca editorial yang konsisten.

> **Jalin ialah tempat menemui cerita.**

## Content pillars

- **Cerpen** — karya asli Jalin.
- **Bersiri** — fiksyen asli Jalin yang berkembang secara episod.
- **Terjemahan** — karya pendek asing yang diterjemahkan oleh Jalin daripada sumber yang sah digunakan.
- **Fragmen** — sedutan terpilih daripada karya panjang domain awam.
- **Sinopsis** — penceritaan semula / ringkasan editorial karya domain awam.

**Novel Pendek bukan lagi kategori Jalin.**

Karya yang panjang boleh kekal pada satu halaman karya dengan pagination dalaman.

## Prinsip awal

- Kurasi dalaman sahaja pada versi awal.
- Ilustrasi editorial menggunakan satu house style visual Jalin.
- Semua karya menyokong glosari ringkas.
- Akaun asas menyokong simpan karya, sejarah bacaan dan sambung bacaan.
- Kandungan percuma pada pelancaran awal.
- AI boleh membantu proses editorial; kawal selia manusia kekal wajib.
- Penulis/penyemak maya menggunakan disclosure yang jelas tetapi tidak mengganggu pengalaman membaca.
- Sinopsis, Terjemahan dan Fragmen memerlukan semakan provenance dan hak cipta/domain awam sebelum READY.

## Stack sasaran

- Next.js + TypeScript
- PostgreSQL
- Self-hosted pada server sendiri untuk fasa awal
- Object storage berasingan untuk media
- GitHub untuk kod dan dokumentasi
- Backup PostgreSQL automatik ke lokasi offsite
