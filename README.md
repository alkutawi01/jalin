# Jalin

**Jalin — oleh Adjung**

Jalin ialah platform fiksyen berilustrasi untuk pembaca remaja berumur sekitar 13–17 tahun. Produk ini menggabungkan cerpen, novel pendek dan karya bersiri dalam pengalaman membaca editorial yang tenang, visual dan mesra bahasa.

## Status

Repository ini baru dimulakan. Keputusan produk yang telah dilock direkodkan dalam `docs/PRODUCT.md` dan dokumen berkaitan.

## Prinsip awal

- Kurasi dalaman sahaja pada versi awal.
- Cerpen, novel pendek dan karya bersiri diberi kedudukan seimbang.
- Ilustrasi digunakan secara editorial dengan satu house style visual Jalin.
- Semua karya mempunyai glosari ringkas pada perkataan terpilih.
- Akaun asas menyokong simpan karya, sejarah bacaan dan sambung bacaan.
- Kandungan percuma pada pelancaran awal, tetapi model data tidak mengunci Jalin kepada percuma selama-lamanya.
- AI ialah alat dalam proses editorial; kawal selia manusia kekal wajib.
- Penulis/penyemak maya boleh mempunyai persona sendiri dan identiti AI diterangkan secara jelas pada halaman bio mereka.

## Stack sasaran

- Next.js + TypeScript
- PostgreSQL
- Self-hosted pada server Adjung/keluarga untuk fasa awal
- Object storage berasingan untuk media
- GitHub untuk kod dan dokumentasi
- Backup PostgreSQL automatik ke lokasi offsite
