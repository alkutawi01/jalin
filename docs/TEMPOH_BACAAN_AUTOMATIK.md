# Tempoh bacaan automatik

Keputusan Izzat, 15 Oktober 2026: tempoh bacaan semua kategori dikira sistem, bukan editor atau bot sembang.

- Satu kaedah: jumlah perkataan teks / 200, dibulatkan ke minit terdekat, minimum 1 minit bagi teks berisi. Teks kosong tidak memaparkan anggaran.
- Cerpen, fragmen, sinopsis dan setiap episod bersiri menggunakan teks karya masing-masing.
- Novela menggunakan pendahuluan dan semua bab; halaman bab menggunakan teks bab itu sahaja. Jumlah siri menggunakan anggaran episod yang diterbitkan.
- Pemformatan Markdown, URL imej dan komen HTML tidak dikira sebagai perkataan bacaan.
- Paparan awam mengira daripada versi terbit, bukan draf yang lebih baharu. Nilai manual lama diabaikan tanpa perlu mengubah atau menerbitkan semula kandungan.
- Borang admin dan semakan import memaparkan kiraan baca sahaja. Servis simpan mengabaikan nilai manual, termasuk klien lama.
- Tiada migrasi atau penulisan pukal produksi diperlukan.
