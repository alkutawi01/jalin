# Jalin Visual Bible v0.1

## House style

Nama kerja: **Soft Cinematic Literary Editorial Illustration**

Kata kunci teras:
**literary · cinematic · warm · restrained**

## Master style

Soft cinematic editorial illustration, semi-realistic digital painting with subtle anime influence, warm muted palette, gentle natural or golden-hour lighting, calm atmospheric depth, elegant literary mood, natural proportions, clean painterly edges, subtle paper-like texture, refined magazine/book illustration quality.

Visual mesti terasa matang, tenang dan sesuai untuk fiksyen remaja premium.

Elakkan:
- photorealism;
- glossy 3D;
- chibi/cartoon;
- comic-book line art;
- exaggerated anime features;
- neon/oversaturation;
- visual clutter;
- decorative effects tanpa fungsi naratif.

## Character continuity

Untuk watak berulang, simpan canonical reference yang meliputi sekurang-kurangnya:
- silhouette;
- tinggi/build;
- tona kulit;
- pakaian utama;
- rambut/tudung;
- aksesori;
- posture/body language.

Jika reference diluluskan sudah wujud, generator tidak boleh mereka watak itu semula daripada teks sahaja.

## Location continuity

Lokasi berulang juga perlu canonical visual reference.

## Magnific workflow

Untuk ilustrasi berulang:
1. gunakan Jalin House Style reference;
2. gunakan character reference bagi setiap watak berulang;
3. gunakan location reference jika lokasi berulang;
4. tambah most-recent approved image jika continuity pakaian/prop/state penting;
5. hasil ialah draft dan mesti dibandingkan dengan reference sebelum diluluskan.

## Editorial illustration rule

Prosa kekal medium utama. Visual menyokong:
- suasana;
- momen naratif;
- identiti siri.

Ilustrasi tidak perlu menceritakan seluruh bab seperti komik.
