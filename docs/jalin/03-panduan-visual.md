# Panduan Visual Jalin

## Gaya Utama

Soft cinematic editorial illustration.

Ciri:
- semi-realistic digital painting;
- subtle anime influence;
- warm muted palette;
- pencahayaan semula jadi;
- mood sastera;
- tekstur halus seperti kertas.

Elakkan:
- photorealism;
- glossy 3D;
- chibi;
- neon;
- gaya komik berlebihan.

Utamakan komposisi, watak, objek dan suasana.
